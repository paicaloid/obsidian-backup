# Algorithms Resources

## Knowledge

- *Learning Algorithms: A Programmer's Guide to Writing Better Code* — George Heineman (O'Reilly, 2021). **Main book.** Python examples, aimed at working programmers. Check the table of contents before starting.
- *Algorithms in a Nutshell* — George Heineman et al. (O'Reilly, 2nd ed). Reference for later, not a first read.

- [LeetCode](https://leetcode.com) — where the problems live; free tier is enough.
- [Python Time Complexity (wiki.python.org)](https://wiki.python.org/moin/TimeComplexity) — operation costs of list, dict, set, deque. Read first.
